# JobSphere – AI Job Portal

JobSphere is a responsive job portal frontend built with React and JavaScript. It helps users explore job opportunities, search listings, save jobs, and manage their applications.

## Features
- User login and signup interface
- Browse and search job listings
- Featured jobs and job categories
- View job details
- Save jobs for later
- Apply for jobs through an application form
- User profile management
- Company listings and contact page
- Responsive user interface

## Tech Stack
- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- Browser localStorage for client-side data persistence

## Getting Started

### Prerequisites
- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/srinitha19/JobSphere-AI-Job-Portal.git
   ```

2. Navigate to the project folder:

   ```bash
   cd JobSphere-AI-Job-Portal
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## Project Structure

- `src/components/` – Reusable UI components
- `src/pages/` – Application pages
- `src/context/` – Authentication context
- `src/data/` – Demo job data
- `src/services/` – API-related logic
- `public/` – Static assets

## Note
This project currently uses demo job data and client-side functionality. Features requiring a backend or live job API depend on the configured services.
